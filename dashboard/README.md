# Phase 10 Dashboard

## Run locally

From the repository root:

```powershell
python -m streamlit run dashboard/app.py
```

The dashboard reads the validated CSV and stored deterministic result files. It does not train models or call paid AI services during rendering. F001–F004, F006 and F007 are shown only with their human-approved qualifications; F005 is deferred and appears only in limitation/audit context.
